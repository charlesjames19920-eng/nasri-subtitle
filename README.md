# Nasri Subtitle Studio

واجهة Gradio لإضافة ملف SRT كمسار ترجمة مستقل داخل MKV باستخدام FFmpeg، دون حرق الترجمة على الصورة، ونسخ الفيديو والصوت دون إعادة ترميز.

## ملاحظات
- يحتاج رابط الفيلم إلى أن يكون رابط تنزيل مباشرًا عامًا.
- هذه النسخة مخصصة للاستخدام الشخصي والتجارب. الاستضافة المجانية لها حدود موارد ومساحة؛ الملفات الكبيرة قد تفشل.
- لا تستخدم روابط خاصة أو روابط تحتوي على رموز دخول سرية.
- لا تُخزَّن الملفات الناتجة بشكل دائم؛ قد تُحذف عند إعادة تشغيل Space.
